# آرتی بیت | Aartybit

فروشگاه استاتیک آرتی بیت برای انتشار روی GitHub Pages.

## فایل‌ها
- `index.html` — ساختار سایت
- `style.css` — ظاهر و طراحی
- `script.js` — محصولات، سبد خرید و فرم ثبت سفارش
- `logo.png` — لوگوی ارسالی

## نکته مهم درباره سفارش
این نسخه بدون بک‌اند است. سبد خرید و آخرین سفارش در `localStorage` مرورگر ذخیره می‌شوند و اطلاعات سفارش به سرور یا شخص دیگری ارسال نمی‌شوند.

برای فروش واقعی، در مرحله بعد باید یک روش دریافت سفارش (مثلاً فرم متصل به سرویس، ایمیل، Google Sheets، تلگرام/ایتا یا بک‌اند اختصاصی) اضافه شود.

## انتشار روی GitHub Pages
1. یک Repository بساز.
2. همه فایل‌های این پوشه را در ریشه Repository آپلود کن.
3. برو به `Settings → Pages`.
4. در بخش `Build and deployment` گزینه `Deploy from a branch` را انتخاب کن.
5. Branch را روی `main` و Folder را روی `/ (root)` بگذار.
6. Save را بزن.

## ریسپانسیو
این نسخه برای موبایل، تبلت، لپ‌تاپ و نمایشگرهای بزرگ با breakpointهای جداگانه تنظیم شده است.
